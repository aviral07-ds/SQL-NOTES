# SQL-NOTES

This repository contains my personal SQL notes, organized topic-wise. Each topic is stored in a separate file so you can read or contribute notes for individual SQL areas (for example, DDL, DML, Joins, Indexes, Transactions, and more).

## Repository structure

- `DDL.SQL` — Notes about Data Definition Language (CREATE, ALTER, DROP, etc.)
- `README.md` — This file
- `LICENSE` — Repository license

More topic files will be added over time. Files are typically named after the topic (for example `joins.sql`, `indexes.md`, `transactions.sql`).

## Table of Contents

- [DDL — Data Definition Language](DDL.SQL)

_More topics will be added here as separate files — check back or open the repository folder._

## How to use

- Browse the files in the repository and open the topic file you want to study.
- Files may use `.sql` or `.md` extensions depending on whether they contain runnable SQL or explanatory notes.

## Contributing

If you'd like to add or improve notes:

1. Create a new file named after the topic, e.g. `joins.sql` or `indexes.md`.
2. Add clear examples and short explanations. Keep each file focused on a single topic.
3. Optionally update the Table of Contents in `README.md` with a link to your new file.

Pull requests are welcome. Keep changes small and focused.
